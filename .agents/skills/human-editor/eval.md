# Human Editor Evaluation Checklist

Before returning an edited draft or UI text, run through these checks:

## 1. Banned Words
- [ ] No banned words: delve, foster, leverage, utilize, facilitate, empower, streamline, robust, cutting-edge, paradigm shift, game changer, this is huge, this changes everything, tapestry, realm, beacon, multifaceted, meticulous, intricate, paramount, transformative, elevate, embark, supercharge, harness, ever-evolving.

## 2. Empty Fillers & Throat-Clearing
- [ ] No empty adverbs acting as filler: just, literally, honestly, simply, actually, truly, fundamentally, importantly, crucially, inherently, inevitably.
- [ ] No throat-clearing openers ("Here's the thing", "Let me be clear", "At the end of the day", "In today's world").
- [ ] No faux-insight setups ("What most people get wrong", "The part everyone misses").

## 3. Sentence Structure & Rhythm
- [ ] No binary contrasts ("Not X, but Y").
- [ ] No colon reveals used for cheap drama.
- [ ] No trailing `-ing` superficial analysis ("highlighting...", "underscoring...").
- [ ] No em dash overuse or default rhythm crutches.
- [ ] No dramatic fragments ("X. And Y. And Z.").
- [ ] Active voice used; inanimate objects don't do human verbs.

## 4. Voice & Content Integrity
- [ ] The author's personal voice, edge, cadence, and vocabulary are preserved.
- [ ] Concrete facts, names, dates, mechanisms, and numbers are protected.
- [ ] No invented claims, statistics, or unsolicited opinions added.
- [ ] Ends cleanly without fake-profound mic-drop aphorisms or generic summary recaps.
